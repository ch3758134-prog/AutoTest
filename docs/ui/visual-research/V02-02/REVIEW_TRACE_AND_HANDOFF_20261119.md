## 4. 研究结论可能被推翻的证据

1. 如果右侧常驻属性迫使步骤内容被截断，不能以“用户喜欢右属性”推定当前实现已经正确；需调整导航、辅助面板响应或考虑 B。
2. 如果底部参数区域导致每屏步骤行太少、频繁垂直定位，不能因 NI 旧截图采用底部编辑就宣称 B 更专业。
3. 如果结构行对比清楚但用户无法在 IF 中指定 THEN/ELSE 插入目标，则视觉与交互未闭环。
4. 如果单击选择后 Inspector 不随对象更新、或离开时丢失不合法输入，则就算图形漂亮也必须拒收。
5. 如果 150% 缩放让字体裁切、窗体宽超出屏幕、编辑命令不能触达，则布局设计未通过。
6. 如果 Ctrl+Space 与中文输入法冲突，就不能照搬 ecu.test 键位；应重新研究快捷键映射。
7. 如果复杂 CAN/UDS/INPUT 专用步骤只能以三类通用字符串字段表达，专业参数设计不合格。
