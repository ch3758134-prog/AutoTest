# A-01｜新主窗口与持续工作入口

日期：2026-11-19；来源：AutoTest R01～R06、用户批准的 UX-PLAN v0.2；身份：UI/UX 研究、设计和纯 UI 实施。

## L0 场景与问题
需要既支持自动测试为主任务，又让各专业工具独立，避免覆盖工程导航和已经打开的工作。

## L1 端到端用户任务
启动后选择任务、编辑测试用例、打开专业工具、回到原任务、退出时处理未保存 UI 内容。

## L2 来源事实 / 研究依据
R03 推荐同一 Shell 的状态化入口而非多余欢迎页；R02 区分 App/Editor/Station/Execution，不把选中当物理写入。

注意：厂商公开资料证明其存在相应机制，不证明 AutoTest 应机械复制。原始资料见 R01～R06、SOURCE_REGISTER；本篇设计取舍属于 UX 候选。

## L3 对象、命令与交互设计
窗口顶部保留全局工作区、保存和当前上下文，左侧仅保留主任务与专业工具快捷入口；中间容器按专业任务更换；副窗口由 Owner 管理。

连续操作脚本：新建/打开/保存 UI 会话、任务导航、工具唤起/激活/关闭、离开未保存会话提示。

## L4 状态、异常与视觉责任
只显示独立 UI 标识和无设备事实，不用假的工程恢复或运行报告填充界面。

所有编辑均作用于 UI 会话。任何离线/UNKNOWN 的实物状态不得在界面中呈现为通过。Windows 小屏、高 DPI、焦点/对话框属于最终跨批验收项。
