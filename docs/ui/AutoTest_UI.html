交互原型 / G3-UX-01 v4

本文件是完全离线的视觉及鼠标交互样本，不能发送 USB/CAN、操作实体工装、读取 ECU 或执行烧录。所有请求只生成明确标注的预览记录。

已确认的产品语义

测试工程 → 测试项目 → 测试用例 → 准备/测试/清理和步骤。工程师可临时勾选测试用例；生产使用规定工序，扫码匹配和真实预检通过后才能自动运行。

手动台架：左 CAN 观察，中工位控制与按键动作，右 CAN 发送。当前 DUT 主电源不受 HOST 控制。IGN、夹具均是独立能力。按键动作不是内置 ECU 业务功能。

按键动作：新增之后可以定义名称、施加态/恢复态 20 位硬件组合、施加前延迟、保持时间、恢复延迟及等待。配置仅表示通过电阻开关网络实现输入时序；不表示有任意电压源或已测到电压。动作与当前工程 Controller 输入状态关联。

UDS：服务目录、请求编辑、UDS 作业、短序列、关联 Trace。真实 UDS 风险服务需后端授权，原型不执行。

波形：多轨道与游标、实际采集与参考、采样质量、独立判定及证据关联。屏幕显示降采样不能当作测试判定数据。

界面可调整工程树、属性栏和观察栏的尺寸及显示状态，常用菜单、快捷键可通过帮助查看。

G3 设计交接边界

现有 TestDocument、TestProjectDocument、Controller、TCF/TBC、DBC、UDS/Wave 的后端模型应继承。HTML 中的数据模型仅用于交互验证，不是新增第二套硬件或 Test DSL。硬件返回 ACK 不等于外部电气或 ECU 已执行。

原型操作路径

顶部“切换工程”选择空白或另一套样例；左工程树打开测试项目与测试用例；步骤右键、Ctrl+Space 编辑；工具栏进入手动台架、DBC、UDS、波形、Flash、生产检测。专业工具可以从当前界面独立打开。
