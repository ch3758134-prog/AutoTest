# AutoTest R1｜手动台架真实硬件控制专项（2026-11-11）

状态：**Windows CI 候选 + 真实 ECU/夹具现场验收待完成**。本专题直接落地 GitHub WPF/DEVICE，不需要另起一套 USB 会话、第二 TEST 执行器、Mock 台架或独立 CAN 驱动。

## 实测前必须核对的硬件事实

- 主控 USB WinUSB → CAN0 为按键模拟板，CAN1 为被测 ECU。设备连接、手动台架、UDS、Flash、TEST 必须复用 `DeviceLabEmbeddedView.Controller` 唯一实例。
- KEY_SIM 的 20 个 bit 是电阻网络开关组合，形成 5 路模拟输出；**不是 20 路可编程电压**。实际 ECU 外部电压需人工测量或有证据的设备采集。
- CAN0 KEY_SIM：标准 CAN ID `0x730`、DLC8，非零 mask 使用 `01 LL MM HH 00 00 00 00`（20-bit）；全部释放使用 `80 00 00 00 00 00 00 00`。USB `CAN_SEND` 主控 ACK 不证明按键板或 ECU 生效。
- IGN：`SET_IGN=0x12`，请求单字节 `1=ON`、`0=OFF`；断开高边并不意味着驱动输出主动拉低。GET 状态是 GPIO，并非实际 DUT 端电压。
- 电磁阀：已归档的主控源码表明 `SET_SOL=0x16`、`GET_SOL=0x17`，操作码 `0=升起` / `1=下落`，GET 为动作编码 / GPIO 读，不证明机械到位。用户现场的现役烧录镜像、气路和末级接线**仍未验收**。
- ECU/按键板/主控当前由现场电源提供输入供电；绝不能把主控 GPIO `ECU_PWR_DRV` 直接解释成真实 ECU 总输入电源开关。

## UI 与操作流程

1. 从主界面“手动台架”进入独立浅色 WPF 窗口，默认正常大小可移动到第二显示器；顶端有“设备连接…”打开共享 Station，不在 Bench 创建新 USB session。
2. 无 Controller Profile 也可勾选 K01~K20，多选组合生成 20-bit mask，勾选仅改变待发送值。**应用选中组合**需要实机会话、版本验证、审计健康、USB Generation 和逐次人工确认。
3. **清空勾选（不发送）**与**释放全部真实按键**为不同操作。释放是单独真实 CAN0 `0x730 / 0x80`，同样逐次人工确认。
4. IGN ON/OFF 经 OneShot PhysicalCommandFence 授权：只有精确 `0x12`+本次一字节 ON/OFF、当前 link generation 可发；默认 DENY；受 TEST 运行/烧录阻断。USB ACK 不产生物理电压判定。
5. 电磁阀升起/下落经独立 OneShot Fence 授权：`0x16`、精确单字节、当前 session/transport generation、人工确认；`GET_SOL=0x17` 可只读获取固件动作状态。不会用 ACK 宣称工装安全夹紧。
6. 可选使用独立 Controller Profile 定义的命名按键状态，仍复用原物理 KEY_SIM 通路。
7. 输入 CH1~CH5 **人工万用表**电压时，记录关联最后一次主控 ACK 的确切 KEY_SIM mask、OperationId，或者当前有效 Controller-state 操作；更改 IGN/电磁阀/Controller 状态/断连会使旧测量上下文失效。未知读数必须保留空白。
8. 本页操作列表含时间、命令、ACK/拒绝、错误和证据指针；原始 USB/物理事实落现役 JSONL，并由设备记录目录保存。

## 必须保留的物理安全限制

- 没有工位版本验证或没有有效 Trace 的情况下，物理输出必须被拒绝。
- CAN0 KEY_SIM、IGN、SET_SOL 使用互相独立的精确一次性许可；CAN1 刷写期间拒绝所有手动输出，正式 TEST 执行期间手动台架端同样拒绝输出。
- UI 不会以“想要 ON/已发出”代替“实际收到 ACK”，更不会把 ACK、GPIO 回读当 DUT/电磁阀实际物理状态。
- USB 断连、超时/异常或会话更换后输出状态为 UNKNOWN；不自动断定复位或安全态，不擅自发送潜在危险的恢复动作。
- 尚未实机实测验证的功能不能宣告 R1 物理完成。

## 本地验收建议

- Win11 窗口：主界面手动台架独立正常窗口、可以拖动；Station 可打开、不会第二次占用 WinUSB。
- 不插设备：20 个按键可勾选、Mask 计算正确，但应用/IGN/夹具不能发出真实命令。
- 连好主控（按实物确认连接）：操作前逐次确认；先只测 KEY_SIM 单 bit、全部释放，导出 USB/JSONL，核查 KEY_SIM 模拟输出五路电压，绝不从 ACK 推断电压。
- IGN：分两次分别操作 ON/OFF，对照实测电压记录；检查断连后界面 UNKNOWN。
- 电磁阀：必须在工装无人、气源与夹具安全条件确认后，独立核验升起/下落动作与 GET_SOL 固件值。未验证之前不纳入自动 TEST 生产。
- TEST/Flash 运行时的人工输出操作必须被拒绝；验证已停止工作后可以重新发起。
- 程序关闭时不自动切换 IGN 或气阀，仅断开共享会话；若硬件保留输出，需要现场物理安全规程处理。
