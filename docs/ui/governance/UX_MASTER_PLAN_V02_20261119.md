## 不可变边界
- **纯 UI**：实现独立可操作的完整 WPF 上位机用户界面，不接 TEST、PROJECT、DEVICE、CAN、UDS、Flash、Wave、Scan、Record 真实后端；不得伪造真实设备状态/运行 PASS。
- **推倒旧 UI**：不沿用 G4 旧 MainWindow、旧 ViewModel、旧工具窗口及交互，不留兼容补丁。后端历史保留于 main，不强迫新 UI 适配其形态。
- **逐批研究、设计、实现、质量检查、强制留档**，不给用户逐批审批；只有实质性产品取舍阻断才问用户。用户最终统一验收完整交互式 UI。
- 研究档案：ui/ide-design；实施分支：feature/ui-full-rebuild-20261119；main 不直接写入。
- 单工位工程测试软件，浅色、中文、Windows 高 DPI，专业工具允许独立副窗口，自动测试为产品工作中心，工具按各自任务布局，不强制三栏。
