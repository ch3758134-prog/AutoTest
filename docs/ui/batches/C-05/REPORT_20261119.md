# C-05｜UDS 服务模板、序列与会话工作区

日期：2026-11-19；角色：UI/UX 全产品研究、设计、纯 UI 实施；状态：DESIGN_CANDIDATE / UI_CODE_COMMITTED / NOT_WIN_VERIFIED。

## L0 专业任务与问题
用户不想反复手工查服务码或只能一次发一条；需要可以保存与连续编辑的请求序列及独立响应时间线。

## L1 成熟产品研究及本项目事实
Vector 的诊断控制台参考参数化诊断函数，R02/R04 反对只读表格与多弹窗。参考：https://www.vector.com/int/en/products/products-a-z/software/canalyzer/

限度说明：以上资料提供成熟工具的机制与本项目用户明确的硬件语义，不是对各厂商最新版的完整上机测试。不能把参考资料的存在当作本界面用户效率已被证实。

## L2 对象、信息与映射
核心编辑对象和关联约束由本批任务决定。当前 UI 仅保存显式命名的编辑草稿、选择状态与用户配置，不编造正式项目修订、DBC codec、UDS/ISO-TP 传输事实或物理电压。

## L3-L4 专业界面与操作方案
左侧 UDS 服务模板（0x10/11/19/22/27/2E/31/34/36/37/3E 等），中间可编辑 HEX 请求序列、启用和顺序，右侧真实响应与会话状态区。编辑脱离连接；执行按钮只在后续真实接线时开放。

**完整用户任务脚本：** 选 0x22→插入请求→修改 DID HEX→插入第二个 0x27→上移→复制/删除→保存并重开 UI 会话。

**状态/异常/可信性：** 模板请求仅是可编辑默认草稿，不假定目标 ECU 支持该服务。NRC、实际响应、请求时间线与 ISO-TP 实时状态均必须来自真实系统。
