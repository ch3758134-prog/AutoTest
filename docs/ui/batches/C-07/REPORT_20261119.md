## L0 专业任务与问题

## L1 成熟产品研究及本项目事实
ETAS INCA 的 YT/XY 示波器允许多测量窗口和游标；官方文档描述游标可用于观察时差与值差。https://docs.etas.com/inca/docs/V7.6/EN/Subsystems/exp/Content/Topics/Platform_Oscilloscope_Create_Cursors.htm

限度说明：以上资料提供成熟工具的机制与本项目用户明确的硬件语义，不是对各厂商最新版的完整上机测试。不能把参考资料的存在当作本界面用户效率已被证实。

## L2 对象、信息与映射
核心编辑对象和关联约束由本批任务决定。当前 UI 仅保存显式命名的编辑草稿、选择状态与用户配置，不编造正式项目修订、DBC codec、UDS/ISO-TP 传输事实或物理电压。

## L3-L4 专业界面与操作方案
左侧信号/单位/参考编辑，右侧图形主体；提供相对时间轴滑块、双游标拖动控制、观察值信息与参考判定入口。没有实际样本时不画伪造测量曲线。

**完整用户任务脚本：** 新增两个信号→编辑名称/单位→调节缩放滑块→移动 A/B 游标→查看间距百分比→尝试参考判定时显示未接线原因。

**状态/异常/可信性：** 当前游标仅表示画布相对位置，不声称测量时间或电机电流值；真实采样、时间戳、质量、参考及比较属于后续集成。
