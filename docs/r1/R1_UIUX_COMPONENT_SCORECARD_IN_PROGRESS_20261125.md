1. **P0 / TEST 项目资源修订按钮假功能：** `TestProjectPackageRow.CanAdoptLatest` 原先恒为 false，`AdoptCurrentRevision()` 空操作。修为基于资源 revision + SHA256 检测过期状态，用户明确确认后更新当前调用实例固定引用。缺失资源保持阻断；只影响指定实例。现有 `TestProjectPinnedRevisionTests` 已有期望，新增同修订不同哈希、临时开发选择不混入正式启用的回归测试源码。

3. **P1 / 测试项目保存使选中行/勾选跳变：** `TestProjectWorkbenchViewModel.SaveAsync` 保存成功后不再 `LoadRows` 清空重建行，保留用户选择、滚动位置、临时勾选集合；历史记录引用修订仍严格显式更新。
