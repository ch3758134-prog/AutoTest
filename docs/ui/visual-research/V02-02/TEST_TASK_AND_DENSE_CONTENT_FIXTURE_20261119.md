## 4. 必须验证的内容与可读性压力

- **中文长名**：「等待某控制器发送状态切换确认并检查信号连续稳定时间」；单行截断时应在当前位置获得完整文本，不能吞掉后缀里真正有区别的部分。
- **长表达式**：`Demo_Status.Ready == 1 && previousMode != currentMode && retryCount < 3`；长文本在详细编辑区有可编辑/可滚动空间，不依赖列表列宽完整显示。
- **长引用名称**：「控制器诊断前置准备及复原操作公共流程」；检验折叠引用、修订与跳转定义能同时辨认。
- **多问题状态**：T09 缺 DBC、T18 无效输入、T29 缺参考；当所属分支折叠时父节点应显示数量摘要。
- **空状态**：用例只有固定三阶段、没有步骤时，仍能清楚添加到正确阶段，不能只剩三条小字和巨大空白。
- **密度状态**：40 条步骤、12 用例、3 个问题与长文本同时存在，观察当前选中/焦点与滚动稳定性。
