# C-03｜综合手动台架与外部激励

日期：2026-11-19；角色：UI/UX 全产品研究、设计、纯 UI 实施；状态：DESIGN_CANDIDATE / UI_CODE_COMMITTED / NOT_WIN_VERIFIED。

## L0 专业任务与问题
手动台架本质是综合外部条件激励与 DUT 观察，不是 20 Key 专用控制器；可视流程必须服务于故障定位和响应收集。

## L1 成熟产品研究及本项目事实
R05 已纠正 KEY 优先的错误。用户确认 20 Key 是电阻组合网络、形成五路模拟电压输出；ECU 业务语义依型号配置。

限度说明：以上资料提供成熟工具的机制与本项目用户明确的硬件语义，不是对各厂商最新版的完整上机测试。不能把参考资料的存在当作本界面用户效率已被证实。

## L2 对象、信息与映射
核心编辑对象和关联约束由本批任务决定。当前 UI 仅保存显式命名的编辑草稿、选择状态与用户配置，不编造正式项目修订、DBC codec、UDS/ISO-TP 传输事实或物理电压。

## L3-L4 专业界面与操作方案
20 Key 采用直达可点击 Toggle；保持时间和组合掩码为一条操作草稿，允许加入可编辑动作列表。IGN/夹具/Can 观察在同一工作场景但真实实体按钮必须受控；请求与响应分层。

**完整用户任务脚本：** 选择多个 Key→设置保持毫秒→保存动作→复制动作→修改组合→切换 CAN 观察标签→删除动作。

**状态/异常/可信性：** 不显示未标定的五路电压目标、不把勾选等同硬件开关状态；所有实体操作禁用并说明未接设备。
