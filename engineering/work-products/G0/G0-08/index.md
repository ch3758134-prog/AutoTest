`OWNER_REPORTED`：自动测试使用扫码枪获取当次 DUT 的唯一编号。`ASSEMBLY/INTERFACE/INTEGRATION/BENCH`：尚无本轮资料证明设备型号、实际接口、扫码字段、软件接入、冲突处理、扫码值与测试记录实际绑定。此缺口应由 `EV-SCAN-01` 关闭，不用固件原理图或历史 HOST 类名替代。

## 偏差/问题与结论

- KEY16 图纸与源码映射不一致；不因此直接推定整板失效，也不得注销问题。
- IGN 输出初始化与注释有不一致风险；优先保护真实上电与危险动作边界。
- 5 路按键网络电压未测；不应用“按键板可输出五路任意电压”的 UI 能力声明。
- 现役 HOST 源码缺失影响 HOST 实现审计，不应阻止完成 PCB 静态能力归档。
