## L2 对象、信息与映射
核心编辑对象和关联约束由本批任务决定。当前 UI 仅保存显式命名的编辑草稿、选择状态与用户配置，不编造正式项目修订、DBC codec、UDS/ISO-TP 传输事实或物理电压。

## L3-L4 专业界面与操作方案
报文列表含搜索；信号表直接编辑信号名/中文别名/起始位/长度/字节序/缩放；右侧报文名称、ID、DLC和位分布，点击行高亮当前信号。新建/删除提供就近命令。

**完整用户任务脚本：** 新建报文→改 CAN ID→增加信号→设置别名和位长→点击信号核对占位→选择另一个报文→恢复当前对象。

**状态/异常/可信性：** 位图目前只是 LSB 顺序区间的 UI 预览，不能将 Motorola、复用/重叠等正式校验当作通过。正式 DBC 导入、解码与版本化不在纯 UI 阶段。
