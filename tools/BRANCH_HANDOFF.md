# Project Control · 分支使用说明

本副本所在的正式研发分支为 `Project_Management`。AutoTest HOST 的正式交付分支仍然是 `main`。

原 `tools/project-control-v2/README.md` 中“只改 main”的说法形成于系统尚未拆分管理分支之前，现已由本分支的治理边界取代。**管理工具的源码变更不应再直接落到 AutoTest HOST 的 main。**

使用时优先读取同目录的 `START_HERE.md` 和 `portable/AI_WORK_MODES.md`，再按照权限与证据完成工作，不要因为分支调整就绕过负责人审批、版本核验、交付审阅或 Gate 流程。

已批准的历史工作产品和工程资产仍在 `SAEF/` 中。本文件是分支切换说明，不表示任何 Gate 获批，也不证明工具完成了端到端实测。
