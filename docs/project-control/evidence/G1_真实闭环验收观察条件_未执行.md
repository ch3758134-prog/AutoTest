# G1｜真实自动测试闭环整体验收条件（研究候选）

目标不是为 EPB 固定一条通用测试用例，也不是要求当前立即上电实测；只规定**第一条针对实际 ECU 的可配置自动测试链**将来必须提供哪些可观察结果，才能称为真正打通。不得将 Mock、纯单测或 UI 截图当成实体 ECU 验收。

| 检查项 | 未来必须观察到的证据 | 与其他能力的关系 | 目前状态 |
|---|---|---|---|
| V-01 工程与程序 | 创建/保存/重开一个用户编辑的测试工程、测试程序，步骤引用保持正确 | 工程↔DBC↔设备资源↔测试编辑 | NOT_RUN |
| V-02 环境刺激 | 适用的 CAN 报文持续周期发送，运行中改变部分信号，其他报文不被中断、重复或改写 | 程序↔CAN↔配置↔共享设备 | NOT_RUN |
| V-03 实际动作 | 经允许对真实 ECU 施加适用的 IGN、KEY_SIM 等动作；命令、应答与实际观测分级 | 设备↔测试步骤↔安全/错误 | NOT_RUN |
| V-04 连续观察 | 实际 DUT CAN RX 与 DBC 解析的目标信号形成有时间来源的连续观测和波形记录 | CAN/DBC↔Wave↔Run | NOT_RUN |
| V-05 规则判定 | 针对有实际数据的配置判据给出预期/实际、时间窗口及波形结果；有效无动作与数据缺失可区分 | Wave/时序↔Runtime↔Verdict | NOT_RUN |
| V-06 运行过程 | 界面展示当前步骤、可见刺激/观测/判据及失败原因；停止与异常不会制造假 PASS | 编辑/运行/设备/证据↔UI | NOT_RUN |
| V-07 结果与证据 | RunId、程序/资源版本、刺激时间、实际 CAN/波形、判据和最终 Verdict 能对应，保留本次完整或不完整归档状态 | 测试↔专业工具↔Record/报告 | NOT_RUN |
| V-08 重复与复核 | 同一保存程序可再次执行并形成独立运行结果；必要时能查看所引用的原始证据 | 程序复用↔Run/Records | NOT_RUN |

**不要求**为满足验收而固定 EPB 的静态驻车/释放、熄火驻车/释放顺序，也不预设具体报文 ID、信号名、电流阈值或采样率。应根据经确认的实际 ECU 测试条件选择代表性步骤与判据。

**前置与边界**：主控与 KEY_SIM 固件当前暂时冻结；根据具体现役固件能力研究 HOST 实现。V-01～V-08 是一项完整链路的验收观察条件，不是 8 个独立模块的通关卡。现阶段不执行实体刺激或烧录；将来上电和夹具动作要满足现场安全条件并由负责人实际操作或授权。

**源码成熟度备注**：main TEST 存在 MockStation，CAN/UDS/Wave 在 Builtins 标为不可执行；PR #27 已有真实只读 CAN/Live Wave/受控 KeySim/记录桥接候选；两者不能混称已通过 V-01～V-08。闭环完成需一个确切版本、一次真实 ECU 测试及相互关联的运行证据。
