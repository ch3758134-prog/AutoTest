## L2 对象、信息与映射
核心编辑对象和关联约束由本批任务决定。当前 UI 仅保存显式命名的编辑草稿、选择状态与用户配置，不编造正式项目修订、DBC codec、UDS/ISO-TP 传输事实或物理电压。

## L3-L4 专业界面与操作方案
左侧可选择固件文件、编辑配置和 Boot 请求/响应 ID 的 UI 候选；右侧阶段列按常见编程流程展现，未执行均明确标识；实际预检、烧录、停止禁用并提供原因。

**完整用户任务脚本：** 选择现有 HEX 文件→填写 Profile 名称→修改 ID→保存 UI 草稿→查看阶段明细→确认没有假字节进度。

**状态/异常/可信性：** 不能自动解析真实固件、不能计算已经传输字节、不能生造 Seed/Key/Routine/Reset 响应；取消请求也不等于真实安全停止。
