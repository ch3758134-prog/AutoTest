# AutoTest｜UI-05 工具窗口交付记录（含 UI-04 / UI-06 联动）

## 基线与边界
- 开发分支：`ui/ui05-specialist-workbenches-20261120`，从 UI-03 HEAD `82224d0f1fc91a67303c9f5bbda44017524f6917` 创建。
- 本轮工程：`UI/AutoTest.TestHiFi`，唯一启动程序仍是 `AutoTest.TestHiFi.exe`。
- 顶部入口统一命名 **工具**，**不提供独立 CAN 工作台**，不删除测试步骤里的 CAN 能力。
- 工具是由主界面创建的 **WPF Owner 绑定子窗口**（同一进程、非独立 EXE），打开后不会覆盖 TEST 编辑区。主界面退出时工具窗口随之关闭。
- 保留已确认的浅色主题；不修改真实 USB、CAN、UDS、Flash、DEVICE 等底层后端。

## UI-05 当前实现
| 工具 | 当前 UI 行为 |
|---|---|
| DBC 编辑器 | 可直接新建 DBC，不强制先导入；支持真实 DBC 文本编辑保存、读取 BO_/SG_ 列表、经字段引导新增基础报文/信号、从工程选择文件；完整语法/跨引用验证尚未接线 |
| UDS 调试 | 参考 UDS Lab 的诊断用例/服务步骤/参数/响应布局；标准 SID 快选、连续请求添加修改删除排序、ID 与响应匹配配置、真实响应区空态，不显示假响应 |
| ECU 烧录 | 固件 HEX/S19/BIN 与 Seed-Key DLL 路径、本地文件存在性检查、应用/Boot ID 编辑、分阶段流程；不显示伪进度 |
| 波形分析 | 独立窗口显示实际导入的两列 CSV（time_ms,value），缩放、适应全幅、交替 A/B 游标和时间差；无实际采样时明确空态 |
| 手动台架 | 20 Key 电阻网络目标组合点击、右键别名、保持时间、序列编辑、IGN/夹具目标；目标不等于实际硬件 ACK |

五个工具都可将其 UI 草稿写入所在本地工作区 JSON 文件；DBC 可直接写实际 .dbc。工具窗口 Ctrl+S 接入相应保存路径。

## UI-04 / UI-06 一并实施
- 测试项目本地 UI 文件，默认一个可编辑用例；准备/测试/清理阶段；勾选启用用例；步骤类型、参数、禁用、移动、复制、删除、缩进、撤销/重做及保存。
- 公共流程独立列表、引用 ID/固定修订，保存时版本推进；调用依赖和循环的执行前检查。
- CAN 步骤从工程真实 DBC 文件选择已有报文和信号，不强制手输 CAN 位定义。
- 运行与调试工作区：运行步骤/当前用例/已启用用例的命令入口、断点、单步与运行到、变量监视、日志/前置检查反馈。
- **真实执行器没有接线**：命令只提供明确阻断原因，不会触发 USB/CAN/UDS/Flash，也不会生成 PASS/FAIL、模拟 ACK、模拟波形或诊断历史。
- 工程恢复包含 TEST 模式、当前用例、阶段及调试面板状态。

## 与正式 AutoTest 研发的边界
本 UI 项目使用 `UiTestProgram` 和 `UiWorkspaceFiles` 作为交互验证与真实本地文件载体，不应冒充正式 TEST DSL、PROJECT Schema 或生产记录；需要在后续受控集成 Gate 执行领域模型及执行器适配。现阶段不能据此认定真实 ECU 自动测试功能已经完成。
