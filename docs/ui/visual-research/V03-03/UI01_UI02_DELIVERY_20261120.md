## 2. UI-02：本地 UI 工作区文件生命周期

所有新建/导入/保存/复制/重命名/移动/删除的文件操作执行真实磁盘 IO；不是纯 UI Toast：
- 新建、打开、关闭本地 UI 工作区（磁盘目录和 `.autotest-ui-workspace.json` 清单）；
- 新建和导入测试程序、公共流程、DBC、波形及配置资源；工程树分类展示并支持右键；
- 多文档打开、关闭、切换、修改的 `*` 状态；Ctrl+S 保存当前、Ctrl+Shift+S 保存全部，另存为独立副本；
- 当前文档 TextBox 撤销/重做；避免将前一个文件的 Undo 单元带到另一文件；
- 重命名资源、复制文件并创建新 ID、移动资源分类、移入工程内回收区、恢复最近删除；
- 关闭有未保存文件的文档/工程/窗口时，保存/放弃/取消三态；最近工程列表及可选会话恢复；
- 路径归一化检查、同名拒绝、Windows 保留文件名拒绝；临时文件写入后覆盖；严格无损读取 UTF-8（包括 BOM）/UTF-16；旧非 UTF-8 文本明确拒绝编辑，禁止乱码回写；
- UI 工作区内部资源间引用暂不自动重写：重命名、移动和删除前明确警告，不能假称引用一致性已自动维护。

## 3. 无法伪装成已实现的能力

- 本版 `.autotest-ui-workspace.json` **不是** 正式 `project.autotest-project.json`，只用于 UI 与实际文件生命周期验收。真实 PROJECT 模型已有独立后端，未来必须以其定义为准，不能将本格式直接当正式测试工程交付。
- 在本预览中导入真实 `.testjson` 或 DBC 后，可以进行无损文本文件操作；**没有**实装正式 TEST 步骤解析、DBC 位编辑、跨资源引用图重写、工程迁移或业务 Schema 验证。
- 专业工具工作页本轮验证全局导航和上下文保持。CAN/UDS/Flash/IO 设备动作、生产扫码和真实日志尚未接线；没有虚构设备 ACK、PASS、生产报表或实时 CAN 数据。
- 右侧 Inspector 现阶段完成了“避免无关 CAN 字段”的最低视觉契约，完整类型化参数编辑、保存和 TEST DSL 仍是 UI-03 的任务。
- 源码静态检查通过不意味着编译通过、运行时布局满足 DPI 或本地磁盘 IO 真实通过。Windows Build/Test/Run 需要用户本地证据。
