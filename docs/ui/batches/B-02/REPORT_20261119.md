## L2-L4 对象、操作、界面和状态设计
测试用例列表、步骤树与持续属性区只属于 TEST 专业工作环境；类型目录在插入点旁；属性名称按具体步骤类型变化，DBC/公共流程通过选择器进入目标字段。

**连续操作验收脚本：** 选测试阶段 → 选 WAIT → 插入 → 设置等待时间 → 选 CAN 判定 → 选择 DBC 报文 → 修改目标值 → 复制步骤 → 上移 → Ctrl+Z 恢复。

**异常及可信状态：** 未完成字段保留在 UI 草稿，不因切换默默丢失；UI 中不声明正式校验通过。步骤实际可执行性须由后端确认。
