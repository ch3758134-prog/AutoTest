## L0 设计问题与目标
测试失败时用户希望能从结果定位用例、具体步骤、日志、波形和报告，不应只看到不可操作的一行 PASS/FAIL。

## L1 研究输入、事实与推论
R05 针对 ecu.test 报告回链研究、NI 报告生成与历史事实分层要求；历史 Run 应与当前草稿独立。

本轮具体窗口方案属于 AI 设计候选，并非行业标准指定布局；历史事实可追溯 R01～R06 与用户最新批准。

## L2-L4 对象、交互、界面和状态
提供历史搜索、时间/DUT/结果/用例的主列表，选择后在详情区展示与冻结事实相关的数据。当前没有真实记录时空列表和解释文字保持可见，报告导出按钮禁用说明原因。

**连续操作任务：** 进入报告历史→输入编号过滤→清除过滤→选择真实行时阅读关联详情；当前没有真实行时不制造记录。

**异常/未接线状态：** UI 会话的扫码输入不能冒充正式历史 Run。查询不到数据、证据不可用和未接服务分别提示。
