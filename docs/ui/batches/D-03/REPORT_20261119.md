# D-03｜设备诊断、工位身份与 UNKNOWN

2026-11-19｜全产品 UI 滚动实施候选｜用户最终 UX 未验收。

## L0 设计问题与目标
测试台由 USB 主控、DUT 总线与按键板总线构成，连接状态、主控 ACK 与 ECU 实际动作必须分开。

## L1 研究输入、事实与推论
用户冻结的物理连接角色（DUT A1/A12、按键板 B1/B11）以及 R05 设备身份/Generation/请求/ACK/真实物理证据分层研究。

本轮具体窗口方案属于 AI 设计候选，并非行业标准指定布局；历史事实可追溯 R01～R06 与用户最新批准。

## L2-L4 对象、交互、界面和状态
设备工具独立窗口：身份和通路在左，过滤/实际事件时间线在右。未有真实 USB 服务时连接/断开明确禁用，显示 UNKNOWN，不猜电磁阀/IGN/输出物理状态。

**连续操作任务：** 打开设备诊断→检查两路总线角色→查询诊断事件→发现目前没有连接→关闭返回自动测试，原编辑状态不丢。

**异常/未接线状态：** 不把用户勾选的 UI 外部输入组合当成真实设备输出，不复用误导性绿色连接/成功标识。
