# 02｜现行要求—取代关系—研究候审总台账

**此表是“哪些结论现在有效”的正式检索索引**，不是重写历史审批原文。状态分级：

- **A / 已批准仍有效**：负责人明确决定且与新事实无冲突；
- **S / 旧要求已取代**：有后续明确决定或物理源码/电路事实纠正；
- **P / 研究建议待评审**：已研究但未获具体方案/门禁批准；
- **I / 源码候选**：已在代码实现但未获全项实测；
- **X / 已废弃工作路线**：不再投入新开发，但原档保留；
- **U / 未证实**：可能合理，缺可信证据，不能以研究推测填补。

同一行可以同时包含 A 的业务约束与 I/U 的实现状态。

## 6. 适用决策方法

- 如同一条旧文档与这里列的**更晚用户明确决定**冲突，按较新批准结果执行，保留旧文档供追溯。
- **物理事实纠错**优先使用原理图、最新对应硬件来源、固件接口和真实测量，不能凭旧产品规划覆盖电路。
- 研究草案如果需要改数据 Schema、生产放行或硬件安全门禁，不能凭“2026-11-21 全面整理已批准”直接视为方案批准。
- 本次未确认的现场波形判定、扫码设备型号/配置、未知 ECU DID、KEY 模拟电压、主控新版 Keil 等仍标 U。
- 历史批准的功能如果暂未实装/实测，不因此自动删除产品需求；区分 `BACKLOG_APPROVED` 与 `RELEASE_P0`。
