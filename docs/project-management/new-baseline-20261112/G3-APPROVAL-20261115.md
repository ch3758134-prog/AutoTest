## 二、G4 允许做与不允许做

**明确允许**：
1. 对旧 `MainWindow`、测试项目/用例编辑器、步骤属性和高频参数弹窗等**相关 UI 代码直接删改或整体重建**，不保留第二套兼容旧界面。
2. 在保持正式 `TestProjectDocument/TestDocument/StepNode/TestTargetMapping` 等真实模型的前提下，为新版 UI 增加必要的工作区状态、编辑事务、DBC 资源绑定、持久化、错误提示与适配服务。
3. 一次性交付从工程打开到测试项目/用例、步骤和流程编辑、Inspector、撤销/保存重开、勾选选择与适用的真实已有执行入口的可用 WPF；对当前无法真实执行的步骤做精确预检/禁用，不假装执行成功。
4. 在受控专用分支提交修改及说明；必要接口矛盾先保留与真实后端一致的安全行为，交付时说明精确差异，**不得自行牺牲 HTML 已认可的视觉和操作**。

**仍然不允许**：
- 未经独立批准的 Flash 0x27/0x31/0x34/0x36/0x37、对 ECU 的实体刷写、篡改 `PhysicalCommandFence` 或设备风险权限。
- 直接将整支 `local` 合并 `main`、未经用户实测擅自合入正式产品、清理真实业务模型或固件。
- 使用 Mock/Replay/随机 Run 事实替代真实硬件，或用 WebView2 包裹 HTML 演示作为正式 WPF。
- 擅自删除已认可的 TEST 步骤入口或将现有不支持的步骤标为已支持。
- 为了形式上的 Gate 结论，把未闭合的 G3-L01～10 当成已验证通过。
