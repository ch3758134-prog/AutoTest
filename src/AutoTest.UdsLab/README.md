# AutoTest · UDS 诊断用例工作台（L5 多服务版）

状态：SOURCE_CANDIDATE / LOCAL_WINDOWS_BUILD_PENDING / REAL_ECU_PENDING

## 用户怎样操作

该窗口不是“发送一条 HEX 然后收藏”。左侧是**完整诊断用例**，中间是该用例的**有序 UDS 服务步骤**，右侧是**当前步骤的可编辑服务、请求、解析**以及独立的**实际 ECU 请求/响应历史**。默认生成一份空白用例及一个空白步骤，不伪造 ECU 的 DID 或响应。

- 新建诊断用例，修改用例名称及备注；在步骤列表添加任意多个服务步骤。步骤支持选择、勾选/禁用、复制、删除、移动上下顺序。
- 选中步骤，就能编辑该步骤的服务、SID/DID/子功能、附加字节、原始 HEX、预期响应及解析方式。选择步骤时不会自动发送。
- 可在任意步骤发单次请求（使用当时的编辑器内容）、运行当前步、执行下一步、从选择的步骤连续执行，或顺序执行整个用例。
- 所有顺序执行都**串行等待每步真正的 ECU 最终响应**；收到 NRC、响应不匹配、取消、失败、超时或不允许发送的服务即停止，不伪装成功；未勾选步骤明确跳过。
- 勾选“连续运行到本步骤前暂停”可在本步前停止，让用户检查前面的 ECU 结果或修改下一步，再点“执行下一步”。
- “跨步骤信息传递”可以为一个步骤的正响应提取固定偏移/长度的真实字节，按名字存入**本次用例执行上下文**；后续步骤可在完整 HEX 请求模板里写 {{变量名}}，运行时替换。变量不会跨断连或重启用例保留；提取失败会停步。
- 中间步骤可编辑后保存到当前用例；顶栏“保存配置”/Ctrl+S 一次性把**整个用例、全部步骤、通信配置**写入 JSON，重新打开可继续编辑。使用 schema 2 保存多服务用例；打开旧版 schema 1、只有 Actions 的 UDS JSON 会逐条转成单步骤用例，而不是丢弃。
- 右侧 ECU 实际交互历史具有 CaseId、StepId、CorrelationId、真实请求和 ECU 响应，修改用例不篡改旧结果；“回填”可将某次历史请求加载到当前步骤草稿后重新调试。日志导出包含真实证据。

## 现有后端与技术边界

- UDS / ISO-TP / CAN / WinUSB 复用已有共享后端和真实主控通信；没有新建一套通用 TEST DSL/执行引擎。L5 运行能力仅限 UDS Lab 内**串行调用已保存的 UDS 服务步骤**，正式 G4 TEST 的变量/IF/ELSE/子过程执行仍归属 TEST 专业。
- 物理发送必须通过每帧人工精确授权 PhysicalCommandFence；因此“顺序运行”仍可能每帧弹授权，也不能宣称完全无人值守或者能够满足严格多帧 ISO-TP 时序。需要 DEVICE/项目管理审批操作级诊断权限后才能解决。
- 实体请求白名单为只读 0x19、0x22、0x23、0x24；0x10 会话控制、0x3E 会话维持、0x11 复位、0x14 清故障、0x27、0x2E、0x2F、0x31、FLASH 等当前尚不能在实机 UDS Lab 直接发送。编辑器支持构造不代表已获实体发送许可。
- 只有真实 ECU 返回的完整响应可产生“有效正响应”和提取变量；USB ACK、CAN 发送尝试、未知结果、NRC 都不能替代。
- 未实现完整 ODX/PDX、通用 IF/ELSE、复杂跨 ECU 诊断序列与权限审批 UI。它们需继续由 PROJECT / TEST / DEVICE 专业协同。
- 不使用 mock，不允许 Codex 自行测试真实 ECU，不运行 CI。网页端修改 GitHub 专业分支，本地 Codex 仅拉取、Windows 编译与启动；用户现场操作并反馈截图/日志。

源码：src/AutoTest.UdsLab；编译输出程序集 AutoTest.UdsLab.exe；独立启动窗口默认最大化，浅色主题。

## 用户验收路径（不含伪 ECU 数据）

1. 断开设备也能建立用例 A，添加两条服务步骤，分别编辑为 0x22 DID 和 0x19 DTC 查询，修改步骤顺序并保存 JSON。
2. 完全关闭软件再打开该 JSON，用例/步骤/参数/停止点/变量规则保持不变，继续修改其中一项并保存。
3. 连接真实 ECU，人工逐帧授权后运行当前步、下一步以及整份用例；每一步结果可以在历史里独立定位；若 ECU 返回 NRC 或不响应，不得自动执行下一步。
4. 可选设置数据提取和 {{变量}} 模板，在本次真实用例运行中确认下游实际请求含预期字节；断连/重连后不能沿用旧变量。

重要：运行使用当前尚未保存的步骤草稿快照，不会自动覆盖文件中的步骤定义。只有“保存步骤”更新用例内的步骤，Ctrl+S 将整份用例写入磁盘。
