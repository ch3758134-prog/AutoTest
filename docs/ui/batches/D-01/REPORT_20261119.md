# D-01｜生产扫码与操作员模式

2026-11-19｜全产品 UI 滚动实施候选｜用户最终 UX 未验收。

## L0 设计问题与目标
生产操作员希望扫码后立即进入可理解的检测任务，不应重新理解全部工程师编辑器。编号重复不能算新增出厂。

## L1 研究输入、事实与推论
R02 NI TestStand Editor/Operator 功能重点区分；用户扫码枪键盘输入、编号绑定与重复不能新增的明确要求。

本轮具体窗口方案属于 AI 设计候选，并非行业标准指定布局；历史事实可追溯 R01～R06 与用户最新批准。

## L2-L4 对象、交互、界面和状态
主工作区单独提供生产扫码页面，突出输入框、当前工位/工程/任务与实际结果。扫码枪 Enter 可捕获本地 UI 输入；本地重复仅作体验提醒，绝不冒充正式数据库查重或自动运行。

**连续操作任务：** 扫码枪输入→Enter→界面展示刚录入编号→重复输入→本地重复提示→观察正式匹配/真实运行仍禁用。

**异常/未接线状态：** 工位未连接、项目未匹配、结果 UNKNOWN。任何输入都不得虚构通过、报告或新增出厂统计。
