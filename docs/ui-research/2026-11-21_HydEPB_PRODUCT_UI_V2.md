# AutoTest UI 产品界面 V2｜绿通 HydEPB 验收说明

**分支**：`ui/research-product-ux-reset-20261121`
**体验入口**：`UI/prototypes/AutoTest_HydEPB_product_ui_v2_20261121.html`
**版本**：2026-11-21 / Gate-Design 体验候选

## 本轮纠偏
1. 删除常态界面中与操作无关的“UI 原型/设计验收/未来接线”说明，仅保留当前设备连接状态、真正的参数错误、操作反馈和必要的阻断原因。
2. 自动测试始终是主窗口工作区，保留完整准备/测试/清理、用例树与常驻参数编辑；工具通过五种独立浏览器子窗口演示，交付正式 WPF 时应对应 Owner 绑定窗口。
3. **手动台架**以可复用按键动作列表为主要操作入口：驻车/释放/无操作已配置；点击编辑才出现 20 Key 与保持时间。支持右键重命名/复制/删除，纯等待（零 Key）。动作结束不暗中 ReleaseAll。
4. 手动台架的 CAN 发送可维护多条报文，按字节直接编辑 DATA，DBC 辅助是可选入口；CAN 监视固定在右侧。
5. DBC 使用用户之前提供的原始 `绿通通信矩阵.dbc` 而非 `Demo_Control`：提取 13 条报文和 113 个信号，保留 CAN ID、扩展帧、字节序、位定义、缩放与源文件中文注释。
6. 工程与文件、生产与记录重新组织为可操作的产品页面，不再出现固定宣传/交付说明；扫码规则最初没有假前缀，没有生产测试结果时显示真实空态。

## 绿通 HydEPB 数据说明
- 用例名称：准备、静态驻车、静态释放、维修释放、熄火驻车。
- K12+K13（驻车）= 0x1800；K7+K8（释放）= 0x00C0；K7+K10（无操作）= 0x0240。示例保持 1000ms。
- 已核对 CAN 输入：0x7B0 / FF EE 00 00 00 00 00 00 单次；VCU_1 0x18FF5027 / 00 20 00 32 00 00 00 00 / 65ms；VCU_2 0x18FFF327 / 00 00 00 00 00 00 00 0C / 65ms。
- DBC 信号：Debug_702.KeyStat（1=无操作、2=驻车、3=释放），Debug_705.ctl_epb_stat（1=驻车、2=释放）。
- **重要限制**：HTML 内用例是依据已确认的历史配置重新整理的交互体验样本，不是原完整 R2 ZIP 的字节级导入。维修释放和熄火驻车需要在后续与原工程逐条校对，不能直接作为真实 ECU 测试程序。

## 验收与实现边界
- Edge/Chrome 双击 HTML，允许弹出工具窗口；无需 Windows Build。HTML 自带 CSS/JS 和演示数据，不依赖 CDN。
- 用户可检验：测试步骤/参数、DBC 13/113、按键动作配置、CAN HEX、UDS 服务序列、烧录文件检查、导入 CSV 波形、扫码配置、撤销/保存/导出。
- 本次测试：浏览器无 JS 异常；步骤/工具弹窗、20 Key、CAN 字节、UDS 序列、Flash 检查、CSV 波形导入成功。
- **不连接设备**：所有物理发送/诊断/烧录/PASS 都不可用；不能用该 HTML 替代正式 R1 `PROJECT/TEST/DEVICE/RECORD`。
- 这是 Gate-Design 候选。正式 WPF 交付必须将这个产品界面应用到 R1 唯一正式后端，不能直接恢复旧版 R1 XAML 外观，也不能移植原型 `UiTestProgram` 等临时领域数据层。
