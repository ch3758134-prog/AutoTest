# 02｜13 个专业页面逐项设计（基于上传的 HTML 实际页面）

每页以 `Pxx` 为稳定设计编号；专业页可以自主完善内部视觉和交互，但不得更改共享资源语义、UI 状态标识和正式运行上下文。下列服务名部分为已有代码概念、部分为建议接口；在 `03` 中注明落地约束。

## P01｜工程中心（原型 `project`，负责人 PROJECT）

**视觉模块拆分：**资源树/工程概要/资源列表/引用图/有效性与缺失资源。

**可执行操作：**新建打开导入；保存、Revision、引用追踪、资源校验、上下文定位。

**ViewModel → 正式服务：**ProjectRepository; ResourceEditService; AssetCatalog; ReferenceValidator。

**状态与错误表现：**不存在资源、重复ID、脏引用、Revision变化、读写冲突。

**设计验证与验收：**工程资源保存→重启→重开；资源被多个专业引用时修改提示。

**最低实现构件：** `View.xaml + ViewModel.cs + Domain DTO/Port Adapter + UnitTests + UI Operation Test + Contract Link`；必须具备 Loading/Empty/Ready/Busy/Error/Disabled 等状态和操作溯源。
