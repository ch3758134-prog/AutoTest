## 二、操作合同（可实际使用）

- 点击**阶段 / 分支**：在当前阶段或明确分支插入；不能向 IF 容器不指定 THEN/ELSE 直接插入。
- 点击**普通步骤**：详情实时切换到对应类型参数；复制/删除/移动保留单次文档级撤销能力。
- **鼠标右键**：插入、复制、内部剪贴板粘贴、上/下移、跨分支移动、包裹为 IF/循环、启用/停用、断点、删除；单步/运行到/跳过在无引擎时禁用。
- **键盘**：Ctrl+S/O 保存/打开纯 UI 草稿；Ctrl+Z/Y 文档级撤销/重做（文本框获焦时优先原生文本撤销）；Ctrl+C/V 复制/粘贴结构；Alt+↑/↓ 同级调整；F2 重命名步骤；Insert 打开插入面板；Ctrl+F 搜索。
- **问题**：双击或单击问题可以定位到对应节点与有错字段；未完成的 `20x` 文本不会被强制转换为 `20` 或丢弃。
- **保留与恢复**：可以保存为 `*.autotest-ui-preview.json` 并重新打开。该文件**不是正式 TEST DSL 或项目文件**。
- **布局**：A/B、窄窗同工作区视图；不通过另外开启属性窗口解决编辑问题。
