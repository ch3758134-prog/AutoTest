# C-04｜输入动作和 ECU 功能映射配置

日期：2026-11-19；角色：UI/UX 全产品研究、设计、纯 UI 实施；状态：DESIGN_CANDIDATE / UI_CODE_COMMITTED / NOT_WIN_VERIFIED。

## L0 专业任务与问题
按键板内部物理网络与 ECU 自定义功能必须区分；各型号信号与识别区间不同，不能直接把 20 Key 写成 20 个驻车/释放功能按钮。

## L1 成熟产品研究及本项目事实
用户先前的真实按键语义澄清 + R05 INPUT-SEMANTICS 的边界说明。不同 ECU 的物理输入配置需要正式域建模，UI 不能擅自推断。

限度说明：以上资料提供成熟工具的机制与本项目用户明确的硬件语义，不是对各厂商最新版的完整上机测试。不能把参考资料的存在当作本界面用户效率已被证实。

## L2 对象、信息与映射
核心编辑对象和关联约束由本批任务决定。当前 UI 仅保存显式命名的编辑草稿、选择状态与用户配置，不编造正式项目修订、DBC codec、UDS/ISO-TP 传输事实或物理电压。

## L3-L4 专业界面与操作方案
左侧 20 个内部开关允许命名；右侧动作集合编辑名称、20-bit 组合 HEX、保持时间和说明；快速从当前 UI 组合构建动作而不执行。

**完整用户任务脚本：** 重命名 KEY 03→在综合台架组合 1/3/6→新建动作→修改保持时间→保存 UI 会话→重新打开。

**状态/异常/可信性：** 组合数值不是电压；五路输出仅是硬件事实说明。正式特性映射、冲突检查和模拟电压标定未接线。
