# AutoTest UI-05｜专业工具工作台交付与验收说明

## 研发范围与冻结边界
- 分支：`ui/ui05-specialist-workbenches-20261120`，从 UI-03 `82224d0f1fc91a67303c9f5bbda44017524f6917` 创建。
- **没有独立 CAN 工作台**；不删除正式自动测试 DSL 的 CAN 发送、接收、解析与判定能力。
- 使用已认可的浅色 UI 外壳和文件会话管理，主界面内切换专业页，不新造第二套主窗口。
- 本阶段为 **UI 工作台交互与本地草稿保存**，不得将界面草稿当成正式 ECU 配置、实测结果或实际执行链。

## 已实施
1. DBC 编辑器：工程现有 DBC 列表、专门导入 DBC、真实文件打开编辑、中文别名方案和信号筛选草稿。
2. UDS 调试：请求 Payload、请求/响应 ID、超时输入，支持连续请求列表添加、删除、上移、下移及本地保存。
3. ECU 烧录：固件文件/Seed-Key DLL 选择、本地存在性检查、应用和 Boot 报文 ID、阶段视觉组织；不显示假进度。
4. 波形分析：工程现有参考 CSV 列表、按参考波形分类导入、打开真实文件、无数据占位、容差及信号草稿。
5. 手动台架：20 Key 组合闭合状态、右键重命名、清空、动作序列、保持时间、IGN/夹具目标草稿。
6. 五个工作页均有统一的导航和右侧配置面板，工具配置可写入当前本地 UI 工作区的实际 JSON 文件；顶部保存 / Ctrl+S 接线。
7. 进入新工程 / 最近工程 / 会话恢复时清理上一工程的工作台草稿缓存；小窗口时隐藏工具二级导航，保留主要编辑宽度。
8. 独立 CAN 工具不出现在工具菜单和快速打开中。

## 未接入及禁止伪造的部分
- 真实 DEVICE USB/CAN/IO/KEY/IGN/夹具指令和 ACK。
- 真实 UDS/ISO-TP 服务发送、响应/NRC 解析和时间线。
- 真实 Flash 编程、Seed-Key DLL 调用、传输与复位阶段。
- 正式 DBC 报文/信号结构化编辑与解析。
- 真实 CAN/波形采样、游标与判定。
- 正式 AutoTest PROJECT/TEST Schema 的专业资源契约。

## 需本地验证
- Windows 构建 / 主界面启动 / 五个工具页切换 / 按键点击与改名 / 请求添加删除调整 / 固件文件选择 / DBC 与参考波形导入 / 工具 JSON 文件保存及重新打开。
- 审查工具布局是否匹配用户已认可的视觉方向。
- 本对话无 Windows 编译环境，所以这些操作未被证明通过；须以 Codex 与用户实际操作证据为准。
