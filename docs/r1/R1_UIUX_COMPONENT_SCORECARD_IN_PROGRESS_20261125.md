## 二、本轮已经提交的可追溯整改

1. TEST Inspector：失败显示原事务错误而不是叫用户去找状态栏；关闭与应用操作合一。
2. TEST 编辑：点击编辑区外部对合法输入尝试提交；不再要求反复“应用并关闭”。
3. TEST 保存：完成后自动持久化，其他步骤修改采用 650ms 去抖排队；新步骤草稿/未完成属性不落盘。
4. TEST 运行：用例/单步启动前持久化当前有效文档，不以人为点“保存”为前提；仍冻结运行快照并保留 Flash 特殊授权。
5. TEST Undo：自动保存不再创建新编辑事务，避免清空 Undo/Redo。
6. 状态事实：纯磁盘保存不再触发已完成运行事实清空，只有实际 TEST 文档改变才失效旧事实。
7. 删除 TEST 顶部重复保存按钮；保留 Ctrl+S 和错误反馈。
