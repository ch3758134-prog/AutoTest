# EPB ECU UI 评审示例工程

## 用途

本目录是实际 AutoTest 工程文件与测试程序资源，不是 UI 中硬编码的虚假运行数据。

通过 AutoTest 的“打开工程”选择 `EPB-UI-review.autotest-project.json`。工程包括：

- **TEST**：准备、测试、清理三个阶段，4 个测试用例，嵌套 IF / WHEN / LOOP、变量、观测、断言和子程序，合计 49 个实际测试节点。
- **DBC**：EPB_Status、EPB_Requests、EPB_Diagnostics 三条示例报文，包含 7 个信号。

这是专门帮助验收 IDE 视觉密度、步骤树、右侧属性、编辑、保存与重开流程的**工程评审样例**。里面的 ID 和信号都是示例定义，不代表任何具体实机 ECU 的合同或已测数据。

不得把测试用例名称、变量名、观测值或样例 DBC 当成真实实测证据。与具体 ECU 实测前，必须配置真实 DBC、控制器按键及设备，逐项核对行为，重新检查程序并获得人工授权。没有配置实机观察与键盘板时不要直接执行。

工程清单资产 SHA-256 与资源真实 UTF-8 字节匹配；修改资源后应在软件中正式保存工程版本，不要手工覆盖并使用旧校验哈希。
