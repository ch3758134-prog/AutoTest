# G2-07｜安全、资源仲裁、证据质量与异常恢复（架构候审 v0.7）

## 现役物理限制

- 12V/24V ECU 由外部工位电源供电，**主控固件无已证实的电源切换权**。
- 夹具只有主控电磁阀控制，没有独立到位传感；CAN 报文不直接证明夹具机械夹紧。
- IGN 控制经主控 GPIO/高边驱动，现场默认状态及实际输出在 B0/B3 复验前不能凭文档推断为安全。
- 当前两份 MCU 固件暂不改，以便得到可比较的现场基线；出现严重问题通过工作包与版本审核修改，实测后定向回归。

## 危险操作前置与拒绝

| 操作 | 不得跳过的条件 | 未满足时 |
|---|---|---|
| 真实 USB / CAN 发送 | 设备身份与当前会话、通道映射、目标适配/供电 | 禁止有副作用的发送；允许受控只读诊断 |
| IGN/夹具 | 线束、适用 ECU 电压、现场环境、气路与安全授权 | 拒绝发令；不得隐式初始化成“安全”状态 |
| 按键输入 | 控制协议/电阻网络/B4可用性 | 不发布未经验证的设备端点 |
| UDS 有副作用服务 | ECU/会话/会话权限与独占发送资源 | 只读观察可继续，危险命令拒绝 |
| 真实刷写 | 目标、HEX、Config、供电、恢复路径、现场单独批准 | 一律拒绝实机 Job，不自动重试或擦写 |

## CAN 资源仲裁

CAN 原始接收可广播给日志/DBC/UDS/波形；发送队列、波特率修改、ECU 诊断会话、IGN/夹具/按键输出要有统一仲裁。`Granted/Waiting/Rejected` 带 LeaseId、Owner、Reason；不能让两个工具同时无序改变同一 ECU 状态。

## 物理/时间/记录证据

`Requested`、`FirmwareAcknowledged`、`CanObserved`、`ElectricalMeasured`、`MechanicalObserved` 和 `OperatorObserved` 是不同证据种类，**不能把它们当做自动升级的一个状态阶梯**。波形时间轴的原始来源、丢帧与采样质量要可见；尚未测定精度前不冻结毫秒级阈值。记录提交失败时禁止宣称已完整归档。

## G3 验证矩阵

USB断连/旧回应；CAN两个订阅者同时运行；诊断与自动测试争用资源；IGN/夹具未知电气状态；错误电压/错误刷写文件；损坏工程与写盘失败；UI状态图标/文字一致。G3 需要将每项变成 Mock/现场用例并保留实测日志。
