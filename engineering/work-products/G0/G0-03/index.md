# G0-03 · 按键板硬件设计事实（输入模拟电路优先）

> SAEF v2.0 / G0-03。**M2 内容候审；本地 G0 仍为 NOT_STARTED，B0～B6 新复验未执行。**本文件仅记录来源可核的板级/代码事实、负责人报告的历史行为和待现场验证事项，三者不能等同。

> **按键板只承担物理按键模拟**；不能简单把它当作“发送 20 位掩码的固件装置”，更不能误称为五路独立可编程电压源。

## 总览及功能电路分解

实际工作机理应先从**DUT 输入电路**看：按键板外部网络通过电阻与模拟开关改变 DUT 输入端的电气条件；20 路开关组合不等于 20 路独立模拟电压。五路模拟网络的实际输出依赖 BAT_KEY/BAT_EPB、开关闭合状态、外接 DUT 端输入阻抗与整车/台架供电条件。

| 页 | 物理域 | 证明的内容（仅设计） |
|---|---|---|
| P1 | JP1/JP2、CANH/L、BAT_EPB、BAT_KEY、BaudRate | 端口与输入网络 |
| P2 | MC9S08DZ32、8MHz 晶振、RESET/BDM、20 路控制信号 | 开关控制的 MCU 资源 |
| P3 | 5×DG411、K1–K20、电阻组合、PARK/RELE/MODE 等 | 实体模拟开关与电阻网络 |
| P4 | MP2451、BATIN、VCC5V 与保护 | 内部逻辑和收发器供电条件 |

## 器件和外围功能

| 对象 ID | 设计位号/型号 | 可见电路 | 页 | 硬件能力边界 |
|---|---|---|---|---|
| KEY-P01 | U3 MC9S08DZ32 | MCU HCS08、CAN 和 GPIO、8 MHz 晶体、BDM | P2 | 器件支持不等于 20 个输出到外部均验收 |
| KEY-P02 | U2 TJA1042T/3（图纸选装注释） | CANL/CANH、TXCAN/RXCAN、SPLIT 与保护 | P1 | 实际装配/终端 1、2 选装必须核实 |
| KEY-P03 | U6–U10 DG411DY | 5 颗 4 路模拟开关，共 20 路 | P3 | 开关电气行为依照器件型号和外围供电，不能假定任意电压 |
| KEY-P04 | R 网络/PARK/RELE/MODE | BAT_KEY/BAT_EPB 相关电阻与开关网络 | P3 | 五路外部模拟信号是网络结果，不是 5 路独立 DAC |
| KEY-P05 | U1 MP2451 | BATIN→VCC5V、保护与电感 | P4 | 板内电源不等于可控 ECU/按键板外部供电 |
| KEY-P06 | BaudRate / AD_BaudRate 网络 | R46/R47/R49 及保护路径 | P1/P2 | 外部输入采样关联，不是对 DUT 的波特率输出 |

**器件资料入口**：NXP S08D `https://www.nxp.com/products/S08D`；ADI DG411 `https://www.analog.com/en/products/DG411.html`；NXP TJA1042 `https://www.nxp.com/products/TJA1042`。以上为产品家族查阅入口；同名 DG411 的厂商、订货后缀、逻辑真值表与实际装配仍须匹配，不能混用不同制造商规格。

**按键 MCU 事实卡**：U3 原理图型号 `MC9S08DZ32`，属于 NXP/Freescale 8 位 HCS08 家族，32 KB Flash 规格；P2 另示 8 MHz 晶体、BDM、RESET 与 20 路 Kx_CTL 控制网络。芯片是否能在某个工作频率及其容差下稳定运行，需要结合时钟配置和实装晶振/供电验证，不能从产品目录的最大参数直接套入板级验收。

**P3 关键电阻网络设计值（直接按图读取，不推导端电压）**：

| 外部网络 | 主要键组及图纸电阻 | 来源与注意 |
|---|---|---|
| `RELE_NC` | K1–K4 相关 R4=470Ω、R5=10kΩ、R7/R8/R14 等 0Ω 设计位 | P3 A 区，串并联/开关组合决定等效路径 |
| `RELE_NO` | K5–K8 相关 R11=470Ω、R15=10kΩ、R16/R17/R18 为 0Ω 设计位 | P3 B 区，端电压依 DUT 输入与 BAT_KEY |
| `PARK_NC` | K9 关联 R19=470Ω、R20=10kΩ | P3 B 区；一组键与多个网络的归属按原图端点检查 |
| `PARK_NO` | K10–K15 区域 R21=470Ω、R22=10kΩ、R23/R24/R25 等 0Ω、R26=270Ω、R27=100kΩ | P3 C 区；列为网络设计资源，不声明每组独立输出 |
| `MODE_NO` | K16–K20 相关 R28=470Ω、R29=10kΩ、R30=0Ω、R31=270Ω、R32=100kΩ | P3 D 区；KEY16 控制管脚存在冲突 |

以上值只代表图纸标注的**设计名义值**，0Ω 位可能承担选装/跨接用途；是否实际焊装、开关后的等效电阻/输出电压仍需现场 BOM 与仪器核对。**尤其不能据此计算并直接发布 DUT 输入端的“五路电压值”。**

**板级能力（由电路而非固件定义）**：

| 能力 ID | 实体路径 | 纸面支持 | 条件与限制 |
|---|---|---|---|
| `CAP-K-CAN` | 外部 CAN → U2 收发器 → MCU | `DRAWING_SUPPORTS` | 选装位、总线供电、终端配置及速率待核实 |
| `CAP-K-SW20` | MCU 20 路控制网络 → U6–U10 的 20 个开关 | `DRAWING_SUPPORTS` | 逻辑单通道独立；组合电气效应不独立 |
| `CAP-K-ANALOG5` | 开关+电阻+BAT_EPB/BAT_KEY→五路 DUT 输入网络 | `DESIGN_SUPPORTS_WITH_CONDITIONS` | DUT 输入阻抗/供电改变实际电压，需真实测量 |
| `CAP-K-BAUD-IN` | BaudRate 网络→AD_BaudRate MCU ADC 引脚 | `DRAWING_PATH_PRESENT` | 该信号是采样输入，不是可编程 CAN 波特率输出 |
| `CAP-K-5V` | 外部 BATIN→U1→VCC5V | `DRAWING_SUPPORTS` | 无权推断主控可软件切断按键板输入供电 |

## 电源时钟复位与保护

按键图 P4 展示电源转换链路，P2 是 8MHz 晶体和复位/BDM 入口；P1 还有 CAN TVS、终端网络及收发器选装注释。设备是否真正实现 20 路“默认全部开路”，不仅依赖 MCU GPIO 初始电平，也依赖模拟开关真实电源与输入状态；必须测量。对外五路网络的安全边界还要核实 BAT_EPB、BAT_KEY 与 DUT 的共地、容许电位及负载。

## 信号/引脚/网络/外部接口

| 电气实体 | 路径 | 图纸证据 | 尚缺 |
|---|---|---|---|
| JP1/JP2 | CANH/CANL、BATIN、BAT_EPB、BAT_KEY、MODE/PARK/RELE 等 | P1 | 实际线束与 DUT 接点/信号含义 |
| U6–U10 | `K1_CTL`…`K20_CTL`→开关→电阻网络 | P2/P3 | 全 20 路 GPIO 真值表、逐路电阻及每组合电压 |
| `K16_CTL` | 图纸标 `PTB3_9P` | P2 | 与现有宏 `PTED_PTED2` 不一致，需现场核对 |
| BaudRate→AD_BaudRate | 输入网络接 MCU ADC | P1/P2 | 真实采样行为、阈值、电气范围 |

**关于五路输出**：建议在后续实测矩阵中区分 `PARK_NO/PARK_NC`、`RELE_NO/RELE_NC`、`MODE_NO` 等外部网络的端点、上拉参考、电阻值、组合闭合条件和 ECU 端实测电压。G0 没有完整实测条件，**不得在这里填写猜测的五组电压**。

## 软件控制关联

后置核查：当前 `WS/EPB_EOL/Sources/APP/KeySim.c` 解析 CAN ID 0x730，用 20 位掩码逐个切换 `KEYn_ON/OFF` 宏；`Driver_Gpio.h` 的 `ON=GPIO 0` 是**代码电平**，不是电压输出值、也是不能据此保证实物开关常态。详细源文件入口与协议限制见 G0-05，特别是 KEY16 的图纸/源码映射冲突。

## 物理约束与证据

- `HW-KEY-01`：实际器件订货型号与 CAN 选装位、DG411 逻辑真值，需实装照片/BOM。
- `HW-KEY-02`：20 路开关的全电气路径与实测对应；仅逻辑掩码不构成通过证据。
- `HW-KEY-03`：5 路实际信号网络的极值、电流和 DUT 输入阻抗条件；需批准场景下的真实测量。
- `HW-KEY-04`：KEY16 `K16_CTL` 设计线与源码 PTE2 差异，不能擅自改固件；需板型及导通证据。
- `HW-KEY-05`：对外供电均由真实台架承担，不能虚构按键板外部电源可控接口。


## 补充：按键板电气网络与开关分组索引（v005）

按键 P3 原图显示五组网络与对应 K1～K20：`RELE_NC`（K1～K4），`RELE_NO`（K5～K8），`PARK_NC`（K9），`PARK_NO`（K10～K15），`MODE_NO`（K16～K20）。注意 K5～K8 区域还有跨网络路径，不能据此将各键简化成完全独立电压源；从图纸分析任何组合必须连同电源、DUT 输入阻抗、选装/0Ω 配置一起核对。

下游 G1 能直接使用的事实是：**20 路开关可配置的电阻网络设计存在、其拓扑和元件值可从 P3 查阅，但没有取得所有动作组合下的 DUT 输入端电压、允许电流和阈值符合性**。此外，KEY16 的 P2 管脚与源码宏不一致是单独差异记录。

## 按键板后续软件身份备注
当前按键 PCB 作为固定输入，现役按键固件用于首次复验。该固件以后仍可迭代；其软件接口与当前电阻网络电气能力不得混为一谈。20 路及 KEY16 的具体有效范围仍须现场观察。

## M2 后续复验与变更边界

本原理图只能支持板级设计事实，不能单独证明现场装配/烧录映像和实际 DUT 操作。B0 在获准现场环境核实线束、供电、电源保护、板卡版本和失电状态；B3/B4 将实际命令响应与电气/机械观察分开记录。任何 PCB 修改须另行评估硬件缺口、修改影响与回归，而非默认 G0 已批准改板。
