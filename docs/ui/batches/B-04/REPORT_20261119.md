R01/R04 直接编辑和属性语义原则；NI Step Settings Pane 证明类型化参数编辑的机制，但并不强制复制其布局。https://www.ni.com/docs/en-US/bundle/teststand-api-ref/page/tsref/step-settings-pane.html

## L2-L4 对象、操作、界面和状态设计
在步骤目录中公开 CAN、IGN、台架、UDS、Flash、Wave 等类型；具体字段标题和说明由 StepInspectorCatalog 决定。DBC 报文、公共流程选择器从同一 UiSession 读取，不生成第二份引用表。

**连续操作验收脚本：** 在 DBC 工具添加报文 → 回 TEST 编辑器选择 CAN 类型 → 引用报文名 → 编辑目标数据 → 返回 DBC 改别名 → 再次打开编辑器查看候选。

**异常及可信状态：** 当前引用只是一份 UI 名称草稿；不伪造正式 AssetId、修订、指纹和运行许可。选不到目标资源时提示先配置。
